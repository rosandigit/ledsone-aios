# TEMPLATE — Evidence Record

Copy this file to `evidence/EVIDENCE_<YYYY-MM-DD>_<TOPIC>.md` and fill in every
field. Where a value is unknown, write `[VERIFY]`. Never guess.

This template is not evidence. It records nothing. An evidence record describes
a file; it never contains the file's contents. Read `evidence/README.md` first.

---

## 1. Record Metadata

| Field | Value |
|-------|-------|
| Evidence ID | `EVIDENCE_<YYYY-MM-DD>_<TOPIC>` |
| Recorded by | Name of the person or AIOS session that wrote this record |
| Date recorded | YYYY-MM-DD |

## 2. Source

| Field | Value |
|-------|-------|
| Source system | Console the file was exported from |
| Report name | Exact report name as shown in the console |
| Ad type | Sponsored Products · Sponsored Brands · Sponsored Display · Other |
| Marketplace | |
| Exported by | Name of the human who exported the file |
| Export date | YYYY-MM-DD |
| Date range covered | YYYY-MM-DD to YYYY-MM-DD |

## 3. Storage Reference

| Field | Value |
|-------|-------|
| Stored in | Platform and folder path as approved in `decisions/DECISION_EVIDENCE_AND_REPORT_STORAGE.md` |
| Sub-folder | Sub-folder within that location, or `—` |
| File name | Exact file name |

Never write a share link, an "anyone with the link" URL, an access token or a
credential here (`CLAUDE.md` Section 9).

## 4. Use

| Field | Value |
|-------|-------|
| Used for | What this evidence supports (for example, a named DRAFT recommendation or report) |
| Baseline sections relied on | `phase-0/PHASE_0_BASELINE.md` sections, or `None` |
| Evidence status | Filed · Superseded · Past retention — removed from storage |
