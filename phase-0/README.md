# phase-0

## Purpose

Holds the Phase 0 baseline for the LEDSone Amazon PPC AIOS: the
Owner-confirmed business baseline recorded on 2026-09-24.

The authoritative record is
[`PHASE_0_BASELINE.md`](PHASE_0_BASELINE.md). Read it directly for every
value. This README deliberately restates **no** baseline value, so that each
fact lives in one place (`CLAUDE.md` Section 13).

`CLAUDE.md` Section 2 makes the baseline the current source of truth until a
later approved decision record in `decisions/` formally supersedes it.

## What belongs here

- `PHASE_0_BASELINE.md` — the Phase 0 baseline record.
- This `README.md`.

## What does NOT belong here

- Changes to baseline values. A baseline value changes only through an approved
  decision record in `decisions/` that names the section it supersedes
  (`CLAUDE.md` Section 2). The baseline file itself is never edited except by a
  separately approved task.
- Copies, summaries or alternative versions of the baseline.
- Later-phase records, decisions, change records, evidence or reports.
- Amazon exports, credentials, customer data or commercially sensitive data
  (`CLAUDE.md` Sections 9 and 10).
