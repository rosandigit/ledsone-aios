# TEMPLATE — Weekly PPC Report

This template defines the structure of the weekly PPC report to the MD
(`phase-0/PHASE_0_BASELINE.md` Section 3.5).

**Never commit a filled-in copy of this template.** Fill it in outside this
repository and save the completed report in the location approved in
`decisions/DECISION_EVIDENCE_AND_REPORT_STORAGE.md`. Only a sent-log record is
added to `reports/weekly/` (see `reports/weekly/README.md`).

Where a value is unknown, write `[VERIFY]`. Never guess.
